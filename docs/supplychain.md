# Jangan Cuma Excel
WHAT ARE THEY?

** 𝐄𝐱𝐜𝐞𝐥 📊 → belajar Pivot Table, XLOOKUP semua tu. Practice guna data dummy inventory/boleh downlod je online excel template.

** 𝐏𝐨𝐰𝐞𝐫 𝐁𝐈 📈 → download Power BI & cuba buat 1 dashboard simple, sales, stock inventory & delivery performance (ni pun aku masih belajar)

** 𝐈𝐧𝐯𝐞𝐧𝐭𝐨𝐫𝐲 📦 → faham basic macam safety stock, reorder, cuba buat simulation stock sendiri dalam Excel.

** 𝐏𝐫𝐨𝐜𝐮𝐫𝐞𝐦𝐞𝐧𝐭 🛒 → kau kena faham flow PR → RFQ → Quotation → PO → Delivery → Invoice. Ini basic flow buyer.

** 𝐋𝐨𝐠𝐢𝐬𝐭𝐢𝐜𝐬 🚚→ belajar beza air freight, sea freight, courier, FCL & LCL. try tengok real shipping case dekat YouTube / boleh je ChatGPT kalau nak paham real case.

** 𝐈𝐦𝐩𝐨𝐫𝐭/𝐄𝐱𝐩𝐨𝐫𝐭 🌏 → start dengan Incoterms macam EXW, FOB, CIF, DAP. Faham siapa bayar apa & siapa tanggung risk semua tu.

** 𝐂𝐮𝐬𝐭𝐨𝐦𝐬 🛃 → faham HS Code, customs declaration, import duty. Tak perlu hafal semua, faham concept je dulu.

** 𝐃𝐚𝐭𝐚 𝐀𝐧𝐚𝐥𝐲𝐬𝐢𝐬 🧠 → jangan sekadar buat graph, train diri kau then jawab: “so what?” contoh: delivery delay naik → why? supplier? transport? lead time how?

** 𝐂𝐨𝐬𝐭 𝐒𝐚𝐯𝐢𝐧𝐠 💸 → ambil satu case simple. Contoh shipping RM8k → cari 3 cara nak reduce cost tanpa kacau delivery (try tanya senior or can ask AI)

** 𝐀𝐈 🤖 → guna AI untuk practice analyse data, create Excel formulas, brainstorm improvement kau but please dont copy-paste blindly.

** 𝐂𝐨𝐦𝐦𝐮𝐧𝐢𝐜𝐚𝐭𝐢𝐨𝐧 🗣️ → practice , ni kat mana2 pun penting (soft skills TOP TIER)

Start dengan 1 skill → 1 mini project → letak dalam CV.
